Инструкция

  1. Выбери раздел: ОГЭ или ЕГЭ, математика или информатика.
  2. Выбери файл с заданиями или включи все файлы раздела.
  3. Отметь, какие задания включать: все, избранные, решённые, прототипы или аналоги.
  4. Нажми «Сформировать персональное ДЗ».

«Одно задание» — все задачи из одного выбранного JSON-файла. «Все задания» — задачи из всех JSON-файлов выбранного раздела.

Раздел берётся прежде всего из поля sectionName в JSON. Если выбрать «Все разделы», задания загружаются без фильтра по разделу. Список обновляется при смене раздела, файла или режима.
