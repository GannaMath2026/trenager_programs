1. Центральный угол = дуге
Центральный угол равен дуге, на которую опирается.
AOB = AB
2. Вписанный угол = ½ дуги
Вписанный угол равен половине дуги, на которую опирается.
ACB = ½ AB
3. Углы на одну дугу равны
Вписанные углы, опирающиеся на одну дугу, равны.
ACB = ADB
4. Угол на диаметр = 90°
Вписанный угол, опирающийся на диаметр, равен 90°.
ACB = 90°
5. Вписанный 4-угольник
Сумма противоположных углов вписанного четырёхугольника = 180°.
A + C = 180°
6. Касательная ⊥ радиусу
Касательная перпендикулярна радиусу в точке касания.
OA l
7. Угол между касательными
Угол между касательными = 180° − центральный угол AOB.
α = 180° − AOB
8. Хорда и касательная
Угол между хордой и касательной = ½ дуги, стягиваемой хордой.
(AB, l) = ½ AB
9. Отрезки касательных
Отрезки касательных из одной точки равны.
PA = PB
10. Хорды: произведение
Если хорды AB и CD пересекаются в P: PA·PB = PC·PD.
PA × PB = PC × PD
11. Касательная и секущая
Квадрат касательной = секущая × её внешняя часть.
PA² = PC × PB
12. Радиус ⊥ хорде
Радиус, перпендикулярный хорде, делит её пополам.
AM = MB
13. Сумма углов Δ = 180°
Сумма углов треугольника равна 180°.
A+B+C=180°
14. Внешний угол Δ
Внешний угол = сумме двух внутренних, не смежных с ним.
ACD=A+B
15. Теорема синусов
Сторона, делённая на синус противолежащего угла, равна 2R.
a / sin A = 2R
16. R описанной окружности
Радиус описанной окружности через сторону и противолежащий угол.
R = a / (2 sin A)
17. Средняя линия Δ
Средняя линия = ½ стороны и параллельна ей.
MN = ½ BC, MN BC
18. S = ½ ab sin α
Площадь через две стороны и угол между ними.
S = ½ ab sin α
19. S = ½ · основание · высота
Площадь через основание и высоту.
S = ½ · a · h
20. S отсечённого = ¼ S
Треугольник, отсечённый средней линией, имеет ¼ площади исходного.
S₁ = ¼ S
21. Угол между биссектрисами
Угол между биссектрисами углов A и C.
AOC = 90° + B/2
22. Теорема Пифагора
Квадрат гипотенузы равен сумме квадратов катетов.
c² = a² + b²
23. Тригонометрические функции
Определения sin, cos, tg, ctg через стороны прямоугольного Δ.
sin A = a/c
cos A = b/c
tg A = a/b
ctg A = b/a
—
—
25. Тангенс острого угла
Тангенс = противолежащий катет / прилежащий катет.
tg A = a / b
26. Основное тригонометрическое тождество
Сумма квадратов синуса и косинуса одного угла равна 1.
sin²A + cos²A = 1
27. Синусы смежных углов
Синусы смежных углов равны.
sin α = sin(180°−α)
28. Косинусы смежных углов
Косинусы смежных углов отличаются знаком.
cos α = −cos(180°−α)
29. Медиана из прямого угла
Медиана из прямого угла равна ½ гипотенузы.
CM = AM = BM = ½ AB
30. Соотношения с высотой
Высота из прямого угла к гипотенузе делит её на отрезки.
BC²=AB·BH
AC²=AB·AH
CH²=AH·BH
CH=a·b/c
31. Радиус вписанной (прямоуг.)
Радиус вписанной окружности в прямоугольный треугольник.
r = (a + b − c) / 2
33. Высота = медиана = биссектриса
В равнобедренном Δ высота к основанию — и медиана, и биссектриса.
BH ⊥ AC, AH = HC
34. Площадь параллелограмма
S параллелограмма = основание × высота.
S = a · h
35. Площадь ромба
S ромба = ½ произведения диагоналей.
S = ½ d₁ d₂
36. Биссектриса параллелограмма
Биссектриса угла A пересекает CD в E. Треугольник ADE равнобедренный (AD = DE).
AD = DE
37. Биссектрисы двух углов
Биссектрисы двух углов при одной стороне пересекаются на противоположной.
DM = AD, CM = BC
38. Средняя линия трапеции
Средняя линия = полусумма оснований.
m = (BC + AD) / 2
39. Середины диагоналей
Отрезок между серединами диагоналей трапеции.
l = (AD − BC) / 2
40. Площадь трапеции
S трапеции = средняя линия × высота.
S = m · h
41. Высоты равнобедренной трапеции
Высоты из вершин меньшего основания отсекают равные отрезки.
AE = FD = (AD − BC)/2
42. Решение через 2 высоты
Опускаем высоты из вершин меньшего основания на большее.
S = ½ (a + b) · h
43. Приём «по двум площадям»
Приравниваем два выражения площади.
½ a hₐ = ½ b h_b
44. Вписанный 4-угольник (признак)
4-угольник вписан ⇔ сумма противоположных углов = 180°.
A+C=180°
45. Описанный 4-угольник (признак)
4-угольник описан ⇔ суммы противоположных сторон равны.
AB + CD = BC + AD
46. Окружность около трапеции
Около трапеции можно описать окружность ⇔ она равнобедренная.
трапеция равнобедренная
47. Окружность в трапецию
В трапецию можно вписать окружность ⇔ сумма оснований = сумме боковых.
AD + BC = AB + CD
48. Равнобедр. трапеция с ⊥ диагоналями
Высота равнобедренной трапеции с перпендикулярными диагоналями = средней линии.
высота = средняя линия,S = h²
