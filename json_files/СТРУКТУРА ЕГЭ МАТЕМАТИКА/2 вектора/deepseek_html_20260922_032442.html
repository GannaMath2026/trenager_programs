1. Координаты вектора
AB = { x₂−x₁ ; y₂−y₁ }
A(1;2), B(4;6) → AB={3;4}
2. Сложение векторов
a+b=c
a{3;1}, b{1;4} → c={4;5}
3. Вычитание векторов
a−b=a+(−b)
a{5;3}, b{2;1} → a−b={3;2}
4. Длина (модуль) вектора
|AB| = √(x² + y²)
AB{3;4} → |AB|=5
5. Сумма и разность через координаты
a+b={x₁+x₂ ; y₁+y₂}
a−b={x₁−x₂ ; y₁−y₂}
a{3;2},b{2;3} → a+b={5;5}, a−b={1;−1}
6. Умножение вектора на число
n·a = {n·x₁ ; n·y₁}
a{2;3}, n=−2 → −2a={−4;−6}
7. Скалярное произведение
a·b=x₁x₂+y₁y₂
a·b=|a|·|b|·cos θ
a{3;0}, b{0;4} → a·b=0
8. Угол между векторами
cos θ = (a·b)/(|a|·|b|)
a{1;0}, b{1;1} → cos θ=√2/2, θ=45°
9. Координаты середины отрезка
M((x₁+x₂)/2 ; (y₁+y₂)/2)
A(1;2), B(5;8) → M(3;5)
10. Деление отрезка в отношении
xM = xA+k(xB−xA)
yM = yA+k(yB−yA)
A(0;0), B(4;8), k=0,25 → M(1;2)
11. Расстояние между точками
|AB|=√((x₂−x₁)²+(y₂−y₁)²)
A(1;1), B(4;5) → |AB|=5
12. Квадрат вектора
a² = a·a = |a|·|a|·cos0° = |a|²
|a|=5 → a²=25
13. Коллинеарность векторов
a∥b ⇔ a=k·b
x₁/x₂ = y₁/y₂ = k
a{2;4}, b{1;2} → k=2, коллинеарны
14. Перпендикулярность векторов
a⟂b ⇔ a·b=0
x₁x₂ + y₁y₂ = 0
a{3;0}, b{0;5} → a·b=0
