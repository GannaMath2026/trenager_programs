Карточки: расположение параболы на промежутке

y = f(x) = ax² + bx + c
Задайте число корней и знаки коэффициентов. В режиме «один набор» будут показаны все расположения только для выбранных знаков; режим «все наборы» выведет отдельные группы друг под другом.

Параметры карточек

Условия. Знаки коэффициентов указаны над графиком. Ниже оставлены только ограничения, необходимые для данного расположения.
«Один набор знаков» показывает все разные расположения для одного выбранного набора знаков a, b, c. «Все сочетания» — отдельный режим: каждая комбинация выводится собственной группой. Вершина на Ox (D = 0) включена отдельно; при a = 0 рассматривается прямая.
