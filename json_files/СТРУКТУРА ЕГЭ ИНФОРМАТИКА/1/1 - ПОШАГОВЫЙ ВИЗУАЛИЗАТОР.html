from itertools import * Импортируем все функции из itertools — нужна permutations для перебора перестановок.
print('*1234567') Печатаем заголовок — просто для красоты вывода.
for per in permutations('ABCDEFG'): Перебираем все 5040 перестановок букв A–G. Каждая перестановка — это гипотеза о соответствии цифр буквам.
p1 = '13 14 16 24 25 36 45 57 67' Цифровая строка рёбер — то, что дано в таблице (связи между пунктами 1–7).
p2 = 'AB AC BC CE AF DG DE DF EG' Буквенная строка рёбер — целевой граф (по картинке).
for a, b in zip('1234567', per): Идём по парам: цифра (a) и буква (b) из текущей перестановки.
p1 = p1.replace(a, b) Заменяем все вхождения цифры a на букву b в строке p1. Так мы «переводим» цифровой граф в буквенный.
if all(c in p2 or c[::-1] in p2 for c in p1.split()): Проверяем каждое ребро: есть ли оно в p2 (или в обратном виде). all() вернёт True, только если ВСЕ рёбра совпали.
print(*per) Если все рёбра совпали — печатаем перестановку. Это ответ!
