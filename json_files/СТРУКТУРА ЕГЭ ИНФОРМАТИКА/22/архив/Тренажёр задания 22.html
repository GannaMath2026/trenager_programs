Алгоритм задания 22

Короткая памятка: порядок действий, столбцы и команды редактора.

📂1. Открыть файл

Скопируйте таблицу, затем на шаге 1 выберите «Из буфера обмена».

▦2. Разделить зависимости

Выделите C:C → Данные → Текст по столбцам → с разделителями → точка с запятой (;).

🎨3. Различать зависимости

Выделите C и D (при 3 зависимостях ещё E) и задайте столбцам разные цвета заливки на вкладке Главная.

＋4. Добавить расчёт

После зависимостей добавьте столбцы окончания предшественников, Начало, Конец, Сдвиг. Сдвиг вводится числом.

▤5. Подготовить таблицу

Главная → Границы → Все границы. Пустые зависимости заменить на 0. Добавьте яркую строку: только A=0, остальные ячейки пустые.

ƒx6. Найти окончания

ВПР ищет ID из C/D в A и возвращает конец процесса из H. Протяните формулу по помощникам и строкам.

↗7. Рассчитать время

2 зависимости: Начало =H2-B2+1, Конец =МАКС(E2:F2)+B2+I2. Для 3: =J2-B2+1 и =МАКС(F2:H2)+B2+K2.

▥8. Сетка Ганта

2 зависимости: шкала с J1, формула в J2: =ЕСЛИ(И(J$1>=$G2;J$1<=$H2);1;""). При 3 зависимостях шкала начинается с L, Начало I, Конец J.

🟩9. Подсветить единицы

Главная → Условное форматирование → Создать правило → значение ячейки равно 1 → зелёная заливка.

↔10. Проверить параллельность

На физической схеме двигайте блоки процессов. Потомки перемещаются вместе; A и B задают временной интервал проверки.

Как пользоваться тренажёром

Короткая памятка на стикерах.

🖥Редактор

Выберите Excel или LibreOffice Calc при запуске. Переключить его можно в верхней панели.

▶Шаги

Нажатие на карточку шага сразу выполняет действие и меняет таблицу.

ℹПодсказки

Кнопка «Подробнее» под шагом открывает стикеры с путём меню, действием и нужными столбцами.

🗂Задачи

«Новая задача» открывает буфер или библиотеку. Сохраняйте номер, условие, таблицу и правильный ответ.

▦Выделение

Щёлкните заголовок строки или столбца; Ctrl+щёлчок добавляет столбцы, Shift+щёлчок выбирает диапазон.

↔Схема и сверка

Перемещайте процессы вместе с потомками, двигайте отметки A/B и сверяйте ответ задачи. Enter тоже проверяет ответ.
