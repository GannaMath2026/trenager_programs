Задание № JSON-04

Запрещённые символы и последовательностиБазовыйВ работе
В файле найдите максимальную длину непрерывного фрагмента, в котором не встречается запрещённая последовательность DFFD.
📚 Теория к задаче · нажми, чтобы открыть или закрыть

re.findall() — все совпадения.

\d — цифра; [A-Z] — заглавная латинская буква.

+ — один или более повторов; * — ноль или более.

[^ABC] — любой символ, кроме A, B и C.

(?=...) — просмотр вперёд, в том числе для перекрывающихся совпадений.

🐍 Код на PythonФайл: 24.txt
import re

f = open('24.txt', 'r')
s = f.readline().strip()
# s = "WNAJFCAZJBVEEUYDFFDKDN23423423PVLXJDVNXCRUMTDWDFFDRDFFDFFWFGPXYHRVEM"

# Регулярное выражение (заполни сам)
pattern = r'(?:(?!DFFD).)+'

matches = re.findall(pattern, s)
answer = len(matches)  # или max(len(m) for m in matches)
print(answer)
Подставлена только регулярка pattern = r'(?:(?!DFFD).)+'. Комментарии и строка s сохранены.
