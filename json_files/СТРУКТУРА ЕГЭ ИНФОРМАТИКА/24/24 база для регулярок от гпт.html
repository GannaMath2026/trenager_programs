Сводка уникальных формулировок из присланных источников. Задачи идут от простых конструкций к составным. Сначала дан шаблон Python re, затем указано, где он решает всё условие, а где служит для извлечения мотивов и нужен отдельный подсчёт.

Как читать список
  • pattern — выражение для Python re, без обрамления r"...".
  • Для максимальной/минимальной длины применяйте finditer или findall и выбирайте совпадение нужной длины.
  • У задач с точным количеством мотивов regex находит позиции мотива; само ограничение по числу обычно требует скользящего окна/двух указателей. Это отмечено отдельно, чтобы не выдавать частичный шаблон за готовый ответ.
  • Техники, уже показанные в лаборатории приложения: классы, серии, альтернативы, отрицательный просмотр, перекрытия, выражения/числа, шаблон «между A». Метка новый прием указывает на расширение за пределы этих заготовок.
