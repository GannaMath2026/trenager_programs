Задача № 27137 — зоны неравенств и ползунок A

Для какого наименьшего целого неотрицательного числа A выражение истинно при любых целых положительных x, y?

(1241651 ≠ 5x + y) ∧ (413184 ≠ x + 2y) ∨ (A > x) ∨ (A > y)

На плоскости показаны отдельные зоны каждого условия. Цвета накладываются полупрозрачно, поэтому видно и каждую зону, и их пересечения. График — схема для анализа областей; проверка ответа остаётся точной алгебраической задачей.
Шаг 1. Диапазон A: от 0 до верхней границы осей (1 300 000). Начальное значение не подсказывает ответ.

\n
x < A y < A 5x + y < 1241651 5x + y > 1241651 x + 2y < 413184 x + 2y > 413184 равенство (исключённая граница)

Диапазон осей: положительные x и y; автоматический масштаб.
