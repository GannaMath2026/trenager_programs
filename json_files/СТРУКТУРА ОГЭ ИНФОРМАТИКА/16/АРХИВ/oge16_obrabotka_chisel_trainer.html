Памятка

Условия для замены слова «УСЛОВИЕ» в коде.

Число чётное

a % 2 == 0

Число нечётное

a % 2 != 0

Делится на 3

a % 3 == 0

Не делится на 3

a % 3 != 0

Оканчивается на 5 в десятичной системе

abs(a) % 10 == 5

Последняя цифра в 7-ричной записи — 5

a % 7 == 5

Трёхзначное число

100 <= abs(a) <= 999

Последняя десятичная цифра нечётная

abs(a) % 10 % 2 != 0
Запомни:
for — когда известно N: сначала вводим N, затем повторяем цикл N раз.
while — когда количество заранее неизвестно: ввод заканчивается числом 0. Сам 0 не обрабатываем.

Среднее = сумма / количество. Перед делением проверь, что количество больше 0.
