Обработка чисел

Условия, счётчики и накопители — короткая памятка перед решением задачи.

1 Условия для проверки чисел
Число чётноеa % 2 == 0
Число нечётноеa % 2 != 0
Делится на 3a % 3 == 0
Не делится на 3a % 3 != 0
Оканчивается на 5 в 10ССabs(a) % 10 == 5
Последняя цифра в 7СС — 5abs(a) % 7 == 5
Трёхзначное число100 <= abs(a) <= 999
Последняя цифра нечётнаяabs(a) % 10 % 2 != 0
2 Счётчики и накопители
Количествоkol = 0
Второй счётчикkol2 = 0
Суммаs = 0
Произведениеpr = 1
Максимумmaxi = -10**10
Минимумmini = 10**10

⬅️ Когда обновлять ДО проверки условия?

Если переменная должна учитывать каждое входное число, обновляй её сразу после чтения числа, до if.

Например: общий счётчик просмотренных чисел, общая сумма, максимум или минимум среди всех чисел.

➡️ Когда обновлять ПОСЛЕ проверки условия?

Если переменная должна учитывать только числа, которые подходят под условие, обновляй её внутри нужной ветки if.

Например: количество чётных, сумма чисел, делящихся на 3, произведение только положительных чисел.

💡
Главный вопрос: «Что именно я считаю или накапливаю — все числа или только подходящие?» От ответа зависит место обновления.
📌
Важно: в одной задаче могут быть оба вида переменных. Например, общий максимум обновляется до if, а количество чётных — внутри if.

Обработка чисел: два шаблона

1. Количество чисел известноЦИКЛ FOR
Сначала вводим N. Затем цикл повторяется ровно N раз.
kol = s = 0
pr = 1
maxi = -10**10
mini = 10**10
a = int(input())
while a != 0:
    if УСЛОВИЕ:
        kol += 1
        s += a
        pr *= a
        maxi = max(maxi, a)
        mini = min(mini, a)
    a = int(input())  # следующее число
print(kol, s, pr)
print(maxi, mini)
print(round(s / kol, 2))  # среднее
2. Количество чисел неизвестноЦИКЛ WHILE
Читаем числа, пока не встретится 0. Стоп-сигнал не обрабатываем.
kol = 0
s = 0
pr = 1
maxi = -10**10
mini = 10**10

a = int(input())
while a != 0:
    if УСЛОВИЕ:
        kol += 1
        s += a
        pr *= a
        maxi = max(maxi, a)
        mini = min(mini, a)

    a = int(input())  # следующее число

print(kol)
print(s)
print(pr)
print(maxi)
print(mini)
⚠️ Не перепутай: в шаблонах выше показан случай, когда счётчики и накопители относятся только к числам, удовлетворяющим условию. Если по задаче нужно учитывать все числа, перенеси соответствующее обновление перед if — смотри памятку на странице 1.
✨ Запомни: for — когда известно N. while — когда количество заранее неизвестно и ввод заканчивается числом 0. Сам 0 не обрабатываем.
